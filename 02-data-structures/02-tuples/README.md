# 02 - Tuples

## What is a Tuple?

A Tuple is an ordered and immutable collection.

```python
customer = ("Ahmed", 25, "Data Analyst")
Access
customer[0]
customer[-1]
Tuple Unpacking
name, age, job = customer
Why Tuples?

Useful for fixed data that should not change.

Examples:

Coordinates
Database records
Configuration values
API responses
